A freelancing marketplace web application where clients post projects and freelancers submit proposals. This project is developed as part of the Software Engineering Lab course.

## Project Goal

Design and implement a web application similar to Upwork and Ponisha, in which:

- Clients post their projects.
- Freelancers browse projects and submit proposals.
- Clients review the proposals and select the freelancer they want to work with.

## Main Roles

| Role       | Description                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------- |
| Client     | Posts projects, reviews proposals, selects a freelancer, and approves delivered work        |
| Freelancer | Builds a profile and portfolio, searches for projects, submits proposals, and delivers work |
| Admin      | Manages users and projects and handles disputes                                             |
